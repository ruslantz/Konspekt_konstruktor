# Физическое развитие в ДОУ — картотеки и конструктор конспектов

Набор офлайн-веб-приложений: картотеки игр, ОРУ, ОВД, строевых упражнений,
ритмики, спортивных игр и конструктор конспекта занятия, который собирает их
всё вместе по перспективному плану или по нужным физическим качествам.

Все страницы рассчитаны на совместное размещение на одном сайте — тогда
правки, сделанные в любой картотеке, автоматически видит конструктор
конспекта (без ручного экспорта-импорта).

## Как опубликовать на GitHub Pages (бесплатно)

Нужен только обычный аккаунт на github.com — своего сервера заводить не надо.

### 1. Создайте репозиторий
1. Зайдите на [github.com](https://github.com) и войдите (или зарегистрируйтесь).
2. Нажмите **New repository** (зелёная кнопка в правом верхнем углу или на
   странице github.com/new).
3. Впишите любое имя, например `fizra-konspekty`.
4. Оставьте репозиторий **Public** (для бесплатного GitHub Pages это должно
   быть публично).
5. Нажмите **Create repository**.

### 2. Загрузите файлы
1. На странице нового (пустого) репозитория нажмите **uploading an existing
   file** (или **Add file → Upload files**).
2. Перетащите в окно браузера **все файлы из этой папки** (`index.html`,
   `games.html`, `oru.html`, `ovd.html`, `stroevye.html`, `ritmika.html`,
   `sportivnye-igry.html`, `konspekt.html`) — все сразу, одним перетаскиванием.
3. Внизу страницы нажмите **Commit changes** (можно оставить сообщение по
   умолчанию).

### 3. Включите GitHub Pages
1. В репозитории откройте вкладку **Settings**.
2. В левом меню найдите раздел **Pages**.
3. В блоке **Build and deployment → Source** выберите **Deploy from a
   branch**.
4. В **Branch** выберите `main` (или `master`, в зависимости от названия) и
   папку `/ (root)`.
5. Нажмите **Save**.

### 4. Откройте сайт
Через 1–2 минуты (иногда до 10) наверху того же раздела **Pages** появится
ссылка вида:

```
https://ваш-логин.github.io/fizra-konspekty/
```

Откройте её — увидите стартовую страницу со всеми картотеками и
конструктором. Эту ссылку можно сохранить в закладки на компьютере и
добавить на экран «Домой» в Safari/Chrome на iPhone — дальше сайт открывается
как обычное приложение, офлайн, без интернета (после первого открытия).

## Что дальше, если что-то меняется

- **Добавили/изменили игру, упражнение или комплекс через форму на
  сайте** — эти правки сохраняются в браузере того устройства, где вы это
  сделали (localStorage), и сразу видны во всех остальных страницах **этого
  же сайта в этом же браузере**, включая конструктор конспекта.
- **Хотите перенести правки на другое устройство** (например, с компьютера
  на телефон) — используйте кнопки «экспорт резервной копии» / «импорт из
  файла» внизу каждой картотеки, как и раньше.
- **Обновили сам перспективный план** (изменили содержание по месяцам) —
  правки нужно внести в файл `konspekt.html` (там, в начале второго блока
  `<script>`, лежит объект `PERSPECTIVE_PLANS`), и снова загрузить этот файл
  в репозиторий (Add file → Upload files, заменить существующий). Сайт
  обновится автоматически в течение минуты.
- **Хотите обновить любую другую страницу** — то же самое: правите файл,
  заново загружаете его в репозиторий с тем же именем, GitHub Pages
  подхватывает изменения сам.

## Важно про приватность

Публичный репозиторий на GitHub означает, что исходный код страниц (включая
встроенные тексты игр и упражнений) технически доступен всем в интернете по
прямой ссылке на репозиторий. Личные правки, которые вы вносите через формы
(localStorage), не публикуются на GitHub и не покидают ваш браузер — они
видны только вам, на вашем устройстве.
